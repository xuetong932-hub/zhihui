# 知回 / KnowBack

v0.4：学习设置、问答、知识库、逐题复习、设备提醒、语音入口与可配置的加密云同步。无第三方运行依赖，建议使用 Node.js 22 或以上。

## 使用

运行 `npm start`，打开 http://127.0.0.1:4174 。运行 `npm run check` 与 `npm test` 检查。端口可通过 `PORT` 环境变量修改；默认仅监听本机。

默认在当前浏览器保存数据。真实模型调用需用户 Key；云账号与跨设备恢复需外部 Supabase 项目，按 [cloud-setup.md](cloud-setup.md) 配置后才可接通。成年确认是本机自行申报，不是身份验证，不能作为正式服务的安全门槛。

## v0.4 当前能力与验证边界

- 模型设置页右上角提供中英配置说明，包括官方 Key 获取链接、地区与业务空间、联网搜索、测试步骤、费用和常见错误。首次打开该页会提示说明入口，关闭后记录到当前浏览器，之后不再重复。说明在原页弹层展示，不清空表单，不发送模型请求。已用浏览器验证首次提示、入口打开、表单保留及重复进入不再提示。

- 一次一道题：文字回答按含义判题；四选一选择题本机判题，出题由用户模型完成。支持猜对、仍不理解、理解、掌握；模型异常不记答错。
- 自适应排程：新卡从次日开始；答错和仍不理解约 10 分钟后重试，猜对次日复习；连续理解后增加间隔，近期错误后的正确答案不直接跳到长间隔。此为可调整的初始算法，不是经过用户数据校准的 FSRS，也不宣称保证记忆效果。
- 每个模块依据最近反馈独立调整难度：连续三次答错或未理解降低一级，五次稳定理解提高一级；用户手动更改水平后重新累积反馈。
- 每日计划按约每题 1.5 分钟估算数量，积压分批安排；主动“自主加练”可包含未到期卡片，正常排程不主动加入当天新卡。周日覆盖本周已学和历史薄弱项；关闭模块、暂停、回收站中的卡不进入队列。
- 复习事件保留作答、判题、反馈、时间和下次日期。错误和未理解在知识库重点标注；复习状态与原始问答独立。
- 可跳过、自由提问；打开时可展示复习弹窗。系统通知需用户主动授权、可关闭、按本地时间设置；当前页面关闭后的定时推送未接通，不承诺离线定时响铃。
- 浏览器语音识别入口：用户点击才启动，不自动发送转写内容，本 App 不保存音频。支持度依设备和浏览器而异；浏览器可能使用其云识别服务，不支持时保留文字及系统键盘语音输入。
- JSON 数据导出不含 Key 或登录凭据。PWA 清单、图标和离线界面缓存已加入，API、Key 和账号请求不缓存。桌面原生安装包和 Android/iOS 安装包尚未构建；网页安装体验依浏览器而异。
- 云端接入代码：邮箱、手机号验证码与 Google/Apple PKCE 登录；AES-GCM 加密备份、可选模型 Key、版本冲突检查、下载替换前本机备份。云端配置、送达、真实 RLS 与跨设备流程尚未用真实项目验证；不是已完成的自动同步。账号绑定合并、中国区服务适配及服务端年龄验证仍待实现。
- 已通过 20 项自动测试，包括排程、重复记录、错误隔离、HTTP接口和加密完整性。隔离浏览器已验证文字判题、错误讲解、选择题、猜对反馈、设备设置以及空云配置拒绝。未测试真实麦克风、系统权限授权、关闭页面后通知或真实 OAuth。
- 已检查约 390 像素视口的复习页，无横向溢出；真实手机硬件尚未验证。发布前仍需原生安装包、账号绑定合并、可靠后台推送及真实云服务联调。

## 第三步：知识库

- 回答成功后自动额外调用一次当前模型提炼核心知识、主题分类和原文生活例子；按启用模块自动归类。请求只携带本条问答和原模块最多 40 个候选标题，不发送其他模块的卡片内容，不额外联网。
- 模型调用可能产生额外费用，模型设置和知识库均有说明。提炼失败时保留原回答摘录，明确标为“待提炼”，可手动重试。历史问答仅在用户点击整理按钮后补充，不因打开页面自动产生补齐费用。
- 相同问题按文本规范化匹配，同义问题由模型在当前模块候选中判断；重复的不同提问记录合并入卡片并标为重点。不把重试同一记录算作新提问。语义判断可能出错，用户可手动修改和合并。
- 按本地日期分组，支持提问日期、模块与文字筛选。每张卡片保留原问答、来源数据、原模块、消息 ID 和日期；暂停或删除不会删除原聊天。
- 支持编辑标题、解释、例子、分类与模块；手动重点、暂停、恢复、同模块合并；删除进入可恢复回收站。合并保留目标说明及全部原始问答。
- 以上为第三步知识库实现记录；v0.4 已让暂停状态参与复习排程。
- 2026-11-01：14 项自动测试通过；Edge 隔离页面验证自动提炼、同义问题合并、重复重点、暂停、回收站恢复与分类修正。成功响应均为明确标注的隔离测试，未使用真实 Key 验证模型提炼质量。

当前第三步预览临时运行于 http://127.0.0.1:4180 ，隔离验收服务为 4181。旧 4174 服务未改动；不同端口的浏览器存储彼此独立，旧记录未自动迁移。常规 `npm start` 默认仍为 4174；若被占用，可先设置 `PORT=4180` 再启动。隔离服务端口可用 `QA_PORT` 设置。

## 第二步使用

1. 在首页进入一个模块，或打开顶部“模型设置”。
2. 选择千问中国区、千问新加坡区或 DeepSeek。填写自己的 API Key；模型名称可按账号可用模型调整。
3. 千问可开启联网搜索。业务空间 ID 从百炼控制台获取；中国区留空时使用官方旧版通用接口，填写时使用业务空间地址；新加坡区必须填写。Key 必须属于对应区域和业务空间。
4. 阅读并勾选发送说明，再保存。保存本身不调用模型；“测试连接”会真实发送一条测试消息，可能消耗额度，且不验证联网搜索。
5. 回到模块发送问题。支持新建对话、历史切换、简化解释、换例子、停止等待和手动重试；来源通过答案下方“查看来源”展开。

API Key 只在当前页面内存中保留，刷新或关闭页面后重新填写，可手动清除。不写入 localStorage、磁盘文件、对话或日志。服务端仅在处理请求时使用 Key，通过 HTTPS 发送给选定服务商；API Key 跨设备加密保存尚未实现。用户无需在聊天中向开发者提供 Key。

问答按照模块和对话分开保存，每条消息包含时间。连续追问最多发送当前对话最近 10 轮完整问答（另有总字数限制），不会混入其他模块、其他对话或失败请求。模型商与搜索可能计费，费用由用户的服务商账号承担。停止等待不能保证服务商停止计费。

当前 DeepSeek 接入只做普通问答，不启用其独立搜索能力；需要联网请选择千问。模型回答无法保证完全准确；没有返回搜索来源时界面不会声称已完成联网核查。不支持此参数的模型会显示错误，不静默降级为未联网回答。

聊天保存在本机浏览器，清理浏览器数据会丢失。存储失败或多页面冲突时显示提示并保留本页可见内容，不覆盖其他页面的新记录。损坏聊天数据不自动覆盖。页面不渲染模型提供的原始 HTML，不加载回答中的远程图片。
